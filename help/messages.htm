Operations with messages

There are several things you can do with messages by right clicking on them:

  1. Editing. Lets you edit your messages. Choosing this option adds the editing button to the toolbar as an indicator. Click on it to cancel editing, or send the message to finish editing.
  2. Replying. Sending a message in the replying state will result in a message which is a reply to the message you picked. Just like when editing, you'll have the replying button on the toolbar.
  3. Forwarding. Allows you to forward messages. The forwarding state is accompained by the forwarding button and stays when going into a different chat, which lets you forward messages to different chats.
  4. Deleting. Deletes messages. You can choose whether to delete the specified message for yourself only or for everyone. Be careful, there's no warning!
  5. Reacting. Right click specifically on the message footer for the reaction selector to appear.
