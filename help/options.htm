Options

Telegacy has several options. The options you choose get applied no matter whether you press the "OK", "Cancel" or the close button.

General

  1. Language. The client's language.
  2. Messages fetch count. How many messages get fetched when opening the chat and browsing chat history.
  3. Current download directory. The files you download go there.
  4. Minimize to tray when closing. This makes the program continue to run in the background after closing it. To actually close it, go to Profile -> Exit on the main menu; the Profile menu is also shown when right clicking on the tray icon.
  5. Use Windows notifications instead of the custom ones. This way, the notifications are shown in the default way for Windows. When unchecked, the Telegacy's custom notifications will be used instead, which is the only possible way if the version of your shell32.dll file is lower than 5.0. If your version is 5.x, the custom notifications bring the additional functionality of being able to click on them to go to the respective chat. With Windows notifications it's only possible if your version is 6.0 or above.
  6. Check for updates on launch. The program will check for updates on startup by connecting to the host server at http://webdav.nixxo.net/telegacy/. Special thanks to NixxO for hosting.

Content

  1. How to load images in chats?
    • Don't load images at all. Shows images as rectangle symbols.
    • Load just the minimal image thumbnails. Telegram sends image messages together with a very small preview, which this option shows.
    • Autodownload and load the bigger sized image thumbnails. The said bigger size is up to 300x300 pixels. These thumbnails don't get downloaded to disk, they stay in memory until the chat is closed. This option also shows stickers.
  2. Enable emojis. When unchecked, emojis are shown as rectangle symbols, and the emoji button on the toolbar gets grayed out.
  3. Apply appropriate formatting to spoilers in chats. Makes the text with the "spoiler" formatting have a black background. Since the text is black, it makes it not visible, in order to see it you need to select it. Since it's a bit of an ugly workaround, you can disable it altogether.

Theme

  1. Main color. The background color of the main window.
  2. Chat color. The background color of the chat, the message input, folder and chat comboboxes, fields in the Profile dialog window.
  3. Dialog color. The background color of dialog windows, as well as of the emoji and reaction choosers.
  4. Text color. The color of all the text.
  5. Individual chat themes. If a Telegram chat theme is set, this will change the main color to the theme's color when opening said chat.
  6. Chat font. Also the font of the message input control and the profiles' "About me" field.
  7. Chat list font. Also the font of the folder list and most of the fields of the Profile window.
  8. UI font.

Sounds

Here you can select the sounds you want for the new message notifications, as well as for the incoming and outgoing messages in the current chat. The sounds have to be in the .wav format. By default, the Windows' notify.wav sound is used for new message notifications; incoming/outgoing messages don't have a sound.

Voice

Here you can choose the sample rate, the amount of bits per sample and channels used when recording your voice messages.

Proxy

Here you can set up your connection to a SOCKS5 proxy. If the IP or port aren't set, the client won't be using a proxy. Username and password are needed if the proxy of your choice requires authentication. They don't matter if the proxy doesn't need any credentials.
