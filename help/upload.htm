Uploading files

Click on the attachment button on the toolbar to select the files you want to upload. After selecting the files and pressing "OK", they'll be added to the list, with the attachment button getting a red indicator. It's also possible to drag and drop files into the application. You can add more or remove some by clicking on them in the list. "Clear this list" option removes all of them. The files will start to be uploaded after sending the message, with the progress shown in the status bar, and the list will be cleared.

Note: if the version of your comctl32.dll is 4.70 or lower, you won't get the dropdown arrow next to the attachment button. To open the list of files selected for uploading, choose the "Show the uploading list" option in the Tools menu instead.

By default, multimedia gets sent as, well, multimedia. However, you can send it as simple files if you check "Send media as files" in the Tools menu. This also allows you to send lots of different files at once, when not possible otherwise.
