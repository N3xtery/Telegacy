Program files

Together with the executable you have:

  1. "help.hlp", "help.cnt" files. The WinHelp version of this user guide.
  2. "help.chm" file. The HTML Help version of this user guide. Is used if the WinHelp version is missing or can't be opened.
  3. "emoji_categories.dat" file. This file contains the different emoji categories and the names of the emojis that are a part of each category. If you want, you can edit this file and change the categories' contents. You can find the structure of this file in the source code.
  4. "emojis" folder. This file contains emojis in the .ico format. Telegacy ships with the Forumoji emojis. You can add missing emojis or replace the existing ones.
  5. "langs" folder. Contains INI localization files in ANSI encoding for different languages. Feel free to make changes or add new languages.
  6. "emoji.ini" file. Has aliases for all the emojis, so you can, for example, type :heart: and the heart emoji will be pasted. Once again, you can do any changes you want.

Also, Telegacy creates new user files in %appdata%/Telegacy/ (in case your system doesn't have %appdata%, "%windir%/Application Data/Telegacy/" will be used). Those include:

  1. "DCs.dat" file. Contains the IP addresses and ports of all the Telegam datacenters, It also tells which datacenter the current logged in account is on.
  2. "session.dat" file. Has everything needed for an access to your account. Updates when you exit the program, except for the sequence number, which is written to this file every 10th time it changes, this measure is needed for the prevention of bad consequences in case of unexpected crashes.
  3. "database.dat" file. Includes data about your chats and folders, as well as the default reactions and themes. Updates when you exit the program.
  4. "fav_emojis.dat" file. Is a list of the emojis you used. Can have a maximum of 40 emojis.
  5. "options.ini" file. Your options are here.
  6. "custom_emojis" folder. The custom emojis you encounter get downloaded to this folder.

When you log out, the "DCs.dat", "session.dat" and "database.dat" files get deleted.
